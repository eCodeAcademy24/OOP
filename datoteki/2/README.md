Да се имплементира класа Movie за претставување на филм. За секој филм се чуваат:

* наслов (title) – стринг,
* режисер (director) – стринг,
* година на издавање (year) – цел број, со почетна вредност 1900.

Да се имплементира класа MovieLibrary која претставува библиотека на филмови и ги содржи следниве податоци:

* име на библиотеката (name) – стринг,
* динамички алоцирана низа од објекти од тип Movie,
* број на филмови во библиотеката.

За класите да се имплементираат:

* оператор << за печатење на филм:

```
<title> directed by <director> (<year>)
```

* оператор << за печатење на библиотека:

```
<name>
<movie1>
<movie2>
...
```

* оператор += за додавање на нов филм. Доколку филмот веќе постои во библиотеката (според сите три полиња), да се фрли
  исклучок MovieAlreadyExistsException, чие што единствено барање е да се испечати пораката:

```
Movie already exists
```

* метод getMoviesByDirector(const string &director, int &numberFound) што враќа динамички алоцирана низа од покажувачи
  кон
  филмови режирани од дадениот режисер. Ако нема такви, да се врати nullptr.

Во главната функција:

Од стандардниот влез се читаат редови со податоци и се запишуваат во датотека input.txt сè додека не се внесе ред со
содржина ----.

Потоа од датотеката input.txt се чита:

* име на библиотеката (1 ред),
* број n на филмови (1 број),

за секој филм:

* наслов (1 ред),
* режисер (1 ред),
* година (1 број)

Секој филм се додава во библиотеката.
Се запишува целата библиотека во output1.txt.
Од стандардниот влез се чита име на режисер.
Се запишуваат сите негови филмови во output2.txt, или "None" ако нема такви.

```
Влез:
CinePlanet
3
The Matrix
Lana Wachowski
1999
Inception
Christopher Nolan
2010
The Matrix
Lana Wachowski
1999
----
Lana Wachowski

Излез во терминал:
Movie already exists
CinePlanet
The Matrix directed by Lana Wachowski (1999)
Inception directed by Christopher Nolan (2010)
Movies directed by Lana Wachowski are:
The Matrix directed by Lana Wachowski (1999)
```
