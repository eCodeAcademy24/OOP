Да се имплементира класа Music за претставување на музичко дело. За секое дело се чуваат:

* наслов (title) – стринг,
* изведувач (artist) – стринг,
* година на издавање (year) – цел број, со почетна вредност 1900.

Да се имплементира класа MusicLibrary која претставува библиотека од музички дела и ги содржи следниве податоци:

* име на библиотеката (name) – стринг,
* динамички алоцирана низа од објекти од тип Music,
* број на музички дела во библиотеката.

За класите да се имплементираат:

* оператор << за печатење на музичко дело:

```
<title> by <artist> (<year>)
```

* оператор << за печатење на цела библиотека:

```
<LibraryName>
<music1>
<music2>
...
```

* оператор += за додавање на музичко дело. Ако делото веќе постои (според сите три полиња), се фрла исклучок
  MusicAlreadyExistsException кој печати:

```
Music "<music>" already exists in the library
```

* метод getMusicsByArtist(const string &artist, int &numberFound) што враќа динамички алоцирана низа со музички дела од
дадениот изведувач. Ако нема такви, враќа nullptr.

Од стандардниот влез се внесуваат редови и се запишуваат во input.txt, сè додека не се внесе ред ----.

Потоа од input.txt се читаат:

* Име на библиотеката (еден ред),
* Цел број n – број на дела,

За секое дело:

* Наслов (еден ред),
* Изведувач (еден ред),
* Година (еден број).

Секое дело се додава во библиотеката.

Потоа:

Се внесува име на изведувач преку стандардниот влез.
Сите дела од тој изведувач се запишуваат во output2.txt, или "None" ако нема.
Содржината од output1.txt и output2.txt се печати на излез.

```
Влез:
MyMusicLib
3
Bohemian Rhapsody
Queen
1975
Imagine
John Lennon
1971
Bohemian Rhapsody

```
