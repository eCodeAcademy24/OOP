# User

## Опис

Во оваа задача треба да се имплементира класа **`User`** во C++, која претставува модел на корисник што може да се
најави со корисничко име и лозинка.

## Атрибути

Класата содржи следните приватни членови:

- `username` (корисничко име) – низа од 50 знаци
- `password` (лозинка) – низа од 50 знаци

## Функционалности

1. **Конструктори:**
    - **Default конструктор**, кој иницијализира корисничко име како `guest` и лозинка `1234`.
    - **Конструктор со параметри**, кој овозможува иницијализација на корисничко име и лозинка.
2. **Getter и Setter методи** – за пристап и измена на атрибутите.
3. **Метода `login()`** – проверува дали внесеното корисничко име и лозинка се точни.
4. **Метода `logout()`** - печати `User {username} is logged out.` ако успешно се логира корисникот односно
   функцијата `login()` врати `true`.
5. **Деструктор** – за уништување на креираниот објект

## Пример за очекуван излез

```
Enter username: john_doe
Enter password: securepass
Login successful. Welcome, john_doe!
User john_doe is logged out.
```
