# Temperature

Да се дефинира класа Temperature во која се чува реална променлива temp. За класата да се дефинираат:

потребните конструктори

changeTemp метода со којашто доколку вредноста на temp е позитивна (сметајќи ја и 0та) ќе се зголеми за еден, доколку е
негативна ќе се намали за еден

get метода за temp.

Забранети се промени во main.

```
Input
4
1 
11.5
2
3
-10.1
4

Output
11.5
1
-11.1
1
```
