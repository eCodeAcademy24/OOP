# Letter

Да се дефинира класа Letter во која се чува еден знак ch. За класата да се дефинираат:

потребните конструктори (подразбирлива вредност за ch е буквата а)

upperLetter метода со којашто ќе се претвори буквата во голема. Доколку не е буква да испечати порака за грешка "
Character is not a letter" (методи за користење: isalpha и toupper).

get метода за ch.

Забранети се промени во main.

```
Input
4
1 
b
4
3
2
2

Output
b
b
Character is not a letter
2
B
```
